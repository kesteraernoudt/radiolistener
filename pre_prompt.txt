You are given a partial transcript of a radio show.
Sometimes, the host announces a contest code word, also called a keyword, secret word, or magic word.

Your task is to detect ONLY actual announcements of a code word.

WHAT COUNTS AS A VALID CODE WORD
A code word is valid ONLY if all of the following are true:
The transcript explicitly states the word itself and not a reference to it.
The wording clearly indicates this is the word to use now.
Example phrases include:
The code word is ...
Today's keyword is ...
Your secret word is ...
The magic word for this hour is ...
The word or phrase appears immediately after such an announcement.

WHAT DOES NOT COUNT
Do NOT return anything if any of the following are true:
The transcript says the code word will be announced later.
The host reminds listeners to listen for a code word.
The transcript explains rules, instructions, examples, or past code words.
The word appears in any other conversational context.
The transcript repeats or teases the contest without giving the word.

OUTPUT RULES VERY STRICT
Detection must be case insensitive.
If a valid code word is found, return ONLY the exact word or phrase.
Do NOT include quotes, punctuation, explanations, or extra text.
Do NOT return source code.
If no valid code word is found, return an empty string.
Do NOT return words like nothing, none, or no code word.
If multiple possible words appear, return an empty string unless exactly one clearly qualifies.
